# cybersecurity-foundations

My cybersecurity learning journey, starting from zero. I'm a Webflow developer and first-semester BS Cybersecurity student, working toward web application security and the security of AI-built apps.

## How this repo works

- One folder per week, with notes written in my own words after I study
- Each week has key terms, a small practical exercise, questions and a short reflection
- I commit as I learn, so the history shows real progress

## Path

| Stage | Topics |
| --- | --- |
| 1. Foundations | Security basics, networking, Linux, operating systems |
| 2. Web security | HTTP, OWASP Top 10, Burp Suite, PortSwigger Web Security Academy labs |
| 3. AI-built apps | Access control, secrets, Supabase and Firebase security, OWASP Top 10 for LLM Applications |
